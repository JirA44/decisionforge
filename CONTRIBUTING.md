# Contribuer à DecisionForge

Installez `python -m pip install -e ".[dev]"`, travaillez sur une branche dédiée, puis exécutez `python -m pytest -q` et `python -m compileall -q src`.

Chaque évolution fonctionnelle incrémente la version, conserve les tests historiques et met à jour OpenAPI. Les scores, classements, recommandations et qualifications sont exclusivement recalculés côté serveur. Aucun statut descriptif ne doit autoriser une action automatique.
